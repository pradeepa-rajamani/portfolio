# 🔐 Security & Engineering Principles

The portfolio follows enterprise integration principles including:

* 🔒 Managed Identity wherever practical
* 🔑 Azure Key Vault for secrets and certificates
* 🛡️ OAuth 2.0 / JWT-based authentication
* 🚫 Avoiding secrets in source code
* 🌐 API gateway security through APIM
* 📉 Rate limiting and throttling
* 🧾 Correlation IDs and distributed tracing
* 📊 Centralised monitoring
* 🔄 Retry and resiliency patterns
* ⚠️ Structured exception handling
* 🏗️ Infrastructure as Code
* 🔁 Automated CI/CD
* 📦 Environment-specific configuration
* 🧪 Automated validation and testing
* 📚 Version-controlled documentation

# 📊 Monitoring & Observability

The portfolio also demonstrates monitoring approaches for Azure integration workloads.

Key metrics include:

| Area            | Metrics                                            |
| --------------- | -------------------------------------------------- |
| APIM            | Request count, response count, latency, error rate |
| Azure Functions | Executions, failures, duration, exceptions         |
| Logic Apps      | Runs, failures, retries, duration                  |
| Data Factory    | Pipeline runs, failures, duration                  |
| Event Hub       | Events, throughput, failures                       |
| Storage         | Transactions, availability, latency                |
| APIs            | 4xx, 5xx, throttling, response time                |
| Security        | Suspicious IPs, unusual access patterns            |
| Platform        | Availability, performance, resource utilisation    |

Future AI-assisted monitoring scenarios include:

* Unusual traffic patterns
* Unexpected traffic spikes
* Slow performance degradation
* Potential DDoS activity
* Token abuse
* Suspicious IP activity
* Credential-stuffing patterns
* Unusual access behaviour
* API error-rate anomalies
